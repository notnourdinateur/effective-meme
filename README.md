# IdeaBoard

IdeaBoard is a dashboard MVP for publishing ideas, organizing them, and leaving room for AI agents later.

## What it includes

- A landing page that introduces the product
- A dashboard for posting ideas
- A shared idea feed with status, visibility, priority, and category
- A future AI agents page for later expansion

## Main routes

- `/` product overview
- `/workspace` idea dashboard
- `/explore` publishing flow
- `/agents` future AI agents placeholder
